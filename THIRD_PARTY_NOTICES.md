# Third-Party References

LLM-KernelLab is independently implemented and benchmarked.

The design and API usage in this repository were informed by the following
open-source projects and documentation:

- Triton language, compiler, documentation, and official tutorials
- PyTorch documentation and RMSNorm APIs
- PyTorch CUDA Extension documentation
- TritonBench benchmark organization

No benchmark numbers from third-party repositories are presented as results
of this project. All reported measurements were collected independently on
the hardware documented in this repository.

Third-party source code is not copied into this repository unless explicitly
identified in the corresponding file.
